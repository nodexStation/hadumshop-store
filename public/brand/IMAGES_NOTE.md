# Brand images in this folder
The workspace source contains 6 genuine HADUM brand JPGs here (hero-brand.jpg, ig-1..ig-5.jpg),
copied from the @hadumshop relaunch content in ~/workspace/instagram-management-hadumshop/assets/.
They are binary files, so the GitHub snapshot push (UTF-8 text only) cannot include them.
When cloning from GitHub, drop the JPGs into this folder with the same names —
the site references /brand/hero-brand.jpg and /brand/ig-1..ig-5.jpg.
